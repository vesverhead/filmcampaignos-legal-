# FilmCampaignOS GitHub Pages Legal Site

Prepared for the public legal/application pages needed by the FilmCampaignOS TikTok integration.

## Before publishing

Replace `REPLACE_WITH_OFFICIAL_CONTACT_EMAIL` in `terms/index.html` and `privacy/index.html`.

Do not put any API key, client secret, access token, refresh token, `.env`, or FilmCampaignOS production source code in this repository.

## Intended URLs

- Home: `https://<github-username>.github.io/filmcampaignos-legal/`
- Terms: `https://<github-username>.github.io/filmcampaignos-legal/terms/`
- Privacy: `https://<github-username>.github.io/filmcampaignos-legal/privacy/`

For TikTok:
- Terms of Service URL → `/terms/`
- Privacy Policy URL → `/privacy/`
- TikTok Desktop OAuth Redirect URI remains `http://localhost:8501/`

These are separate settings.
